Your ad report says revenue. This says profit.

Brand OS is an open-source operations platform for Shopify and D2C brands. It joins orders, ad spend, shipping and overhead into one number that matters: the exact ROAS each product must beat before a campaign starts losing money.

Get it on GitHub Run it in 3 commands No SaaS. Your data stays on your server.

Break-even ROAS, from real unit economics

Most calculators ask you to guess a margin. Brand OS derives it from what a unit actually costs you — landed cost, shipping, and this month's overhead spread across units sold.

overheadPerUnit = (rent + salaries + other) / unitsSoldThisMonth grossProfit = sellingPrice - cogs - shipping - overheadPerUnit margin = grossProfit / sellingPrice BEROAS = 1 / margin
at or above target — healthy within 10% below — warning further below — critical
What it does

Built for the costs other dashboards ignore

Cash on delivery, failed deliveries and offline market stalls are normal in most of the world. Brand OS treats them as first-class, not edge cases bolted on later.

True profitability per product

Net margin after COGS, shipping, returns and allocated overhead — with a margin-versus-revenue map that separates what to scale from what quietly loses money on every order.

COD reconciliation

Track cash still uncollected by courier, and the failed deliveries that silently eat margin in cash-on-delivery markets.

Inventory & restock

Stock across warehouse, storefront and events, with restock planning and size-level demand signals.

Offline POS

Sell at bazaars and pop-ups against the same inventory, with per-event stock and settlement history.

Blended ROAS against its break-even target

Campaign health as a computed verdict rather than a vibe: measured return on ad spend, compared against the margin-derived number it actually has to clear.

Install

Running locally in three commands

Docker Compose brings up PostgreSQL, Redis, the API and the web app. The stack refuses to start without real secrets — no deployment silently runs on a default key.

# 1. clone
git clone https://github.com/azzazy967/brandos.git && cd brandos

# 2. generate secrets (the stack will not boot without them)
printf 'POSTGRES_PASSWORD=%s\nJWT_SECRET=%s\nENCRYPTION_KEY=%s\n' \
  "$(openssl rand -hex 16)" "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > .env

# 3. build and seed
docker compose up -d --build
docker compose exec backend npx prisma db push
docker compose exec backend npx tsx prisma/seed.ts

Then open http://localhost:3001. Full instructions, including running without Docker, are in the installation guide.
